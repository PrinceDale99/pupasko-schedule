# Who's Free · Shoot Planner

Shows which cast and crew are out of class at any time, their next class, and the best shoot windows.

- `src/data.js` holds everyone's schedule. Edit it when a schedule changes.
- Built with Vite + React and [glisse](https://github.com/0kzh/glisse) (iOS 26 Liquid Glass).

## Run locally

    npm install
    npm run dev

## Deploy

Push this folder to GitHub and import it in Vercel. It detects Vite automatically
(build `npm run build`, output `dist`). No settings needed.
